# MirrorDrop

iPhone 화면을 같은 Wi-Fi에 있는 TV(Google Cast 지원 기기)로 보내는 무료 iOS 앱입니다.
지금은 **첫 출시(1.0) 준비** 중입니다. 순서는 [docs/RELEASE.md](docs/RELEASE.md).

- 사진·영상 감상이 목적입니다. TV에는 약 4초 늦게 나옵니다.
- 화면 영상은 집 안 Wi-Fi 밖으로 나가지 않습니다. iPhone이 직접 TV에 건네줍니다.
- Mac 없이 GitHub Actions(공개 저장소)에서 빌드하고, TestFlight로 iPhone에 설치합니다.
